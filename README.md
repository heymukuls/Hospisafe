# Hospisafe

Hospital hygiene and sanitation management, designed for housekeeping teams and hospital administrators.

## Stack
- Next.js App Router
- React + TypeScript
- Tailwind CSS
- PWA-ready manifest and service worker

## Local development
```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Environment
Copy `.env.example` to `.env.local` when backend configuration is added. Never commit real credentials.

## Current milestone
The starter includes a branded splash screen, responsive sign-in entry point, manifest, and installable-app foundation. Authentication and persistent records will be wired to a backend in a later milestone.
