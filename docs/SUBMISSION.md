# Hackathon submission checklist

- [ ] Public repository URL added to the hackathon submission page.
- [ ] Working demo URL: https://hospisafe.online
- [ ] Public Admin demo and Staff demo both tested in a private browser window.
- [ ] `GET /api/health` returns `status=ok` and `database=connected`.
- [ ] One task has been completed in Staff demo and verified in Admin demo.
- [ ] Demo video is publicly accessible and at most 2 minutes long.
- [ ] Description is under 280 characters.
- [ ] `git status` reviewed; `.env`, database credentials, cookies, patch backups and logs are not staged.
- [ ] Latest source and migrations committed and pushed before the hackathon's Git cutoff.

## Project description (under 280 characters)

Hospisafe helps hospitals manage hygiene end to end: map floors and areas, organise housekeeping staff, assign daily routines and urgent cleaning tasks, track staff checklists, and verify every completion with an activity history.
