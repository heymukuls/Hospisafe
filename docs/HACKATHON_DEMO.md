# Hospisafe — 2-minute demo walkthrough

**Demo URL:** https://hospisafe.online  
**Goal:** show one administrator-to-staff hygiene workflow end to end.

| Time | Screen / action | Narration |
|---|---|---|
| 0:00–0:12 | Open the landing page; show Hospisafe branding and the Admin / Staff demo entry points. | “Hospisafe brings hospital hygiene operations into one accountable workspace.” |
| 0:12–0:30 | Enter Admin demo. Show hospital name, floor / department / area setup and staff list. | “Administrators map the hospital's spaces and organise the housekeeping team.” |
| 0:30–0:48 | Show an existing task or create a Special task assigned to the demo staff member. | “A one-time task can carry its location, priority, assignee and due time.” |
| 0:48–1:02 | Show the Daily routine action and its daily due time / start date. | “Routine cleaning can be set up once and generated as a separate daily assignment.” |
| 1:02–1:25 | Sign out; enter Staff demo. Open an assigned task, start it and tick the checklist. | “Staff see their own assigned work, follow the checklist and submit when finished.” |
| 1:25–1:45 | Submit the task; sign in as Admin demo again and show the changed status / verification action. | “The administrator can review completion and verify the record.” |
| 1:45–2:00 | Close on the dashboard and Hospisafe brand. | “Every space. Every clean. Every record.” |

## Recording notes

- Use the public demo buttons and sample tenant only.
- Do not show passwords, browser password managers, `.env`, database consoles or real staff / patient information.
- Keep the browser zoom at 90–100% and use a desktop viewport for the Admin view. Include a quick mobile-width view of the Staff portal if time allows.
- Record one uninterrupted pass where possible. The submitted video must be no longer than two minutes.
- If the Daily routine list is empty, show the routine setup form; do not claim a background job runs exactly at the scheduled time. Today's routine task occurrence is generated when the task list is requested.
